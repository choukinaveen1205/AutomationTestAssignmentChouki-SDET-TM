In Scope
-------------------------------------
User Login functionality
User Registration
Product Search

Test Levels
--------------------------------------
UI Testing (End-to-End): Validates application behavior through the browser using Selenium.
Functional Testing: Ensures features work as expected from a user perspective.

Test Types
-------------------------------------
Positive Testing: Valid scenarios with expected inputs (e.g., successful login, valid product search).
Negative Testing: Invalid inputs and edge cases (e.g., incorrect login, empty registration form).
Validation Testing: Verifying error messages and field validations.

Execution Strategy
-------------------------------------------
Tests are automated using Selenium WebDriver with C#
BDD approach implemented using SpecFlow
Tests can be executed via:
Visual Studio Test Explorer
Test --Run ALL
